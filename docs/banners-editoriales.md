# Banners por colección o editorial

## Separadores en la página de inicio

La portada incluye un **Separador de colección** antes de los grupos de Alianza, Planeta y Alba. El separador muestra únicamente la imagen que selecciones, sin panel de color, títulos ni botones extra. Puede inclinarse suavemente al mover el cursor y al hacer scroll. Se respeta la preferencia de movimiento reducido del visitante.

Para personalizarlo: **Personalizar → Página de inicio → Separador de colección**. Selecciona la colección, sube el banner para escritorio y, opcionalmente, otro para celular. La imagen enlaza a la colección. Puedes desactivar el efecto con **Activar movimiento 3D suave**.

Si no hay imagen seleccionada, el separador se oculta para los visitantes. En el editor se muestra una ayuda para subirla. El nombre de accesibilidad describe la imagen para lectores de pantalla; no se imprime visualmente.

Estos separadores de portada son independientes del banner dentro de la página de cada colección, que se configura a continuación.

La plantilla predeterminada de colección incluye la sección **Banner de editorial**, encima del encabezado y los productos.

## Asignar un banner

1. En Shopify, abre **Tienda online → Temas → Personalizar**.
2. En el selector de páginas, elige **Colecciones → Colección predeterminada** y abre una colección de editorial para previsualizarla.
3. En **Banner de editorial**, pulsa **Agregar bloque → Editorial**.
4. Selecciona la colección correspondiente y su banner para escritorio.
5. Opcionalmente, escribe el nombre de la editorial, añade un texto breve y selecciona un banner para celular.
6. Repite con las demás editoriales y guarda.

Los bloques se comparten en la plantilla, pero cada banner aparece exclusivamente en la colección seleccionada. Si hay dos bloques para la misma colección, se utiliza el primero. Para cambiar un banner, edita ese bloque.

## Alternativa: imagen propia de cada colección

Activa **Usar la imagen de cada colección si no tiene banner asignado**. Entonces puedes subir una imagen distinta desde **Productos → Colecciones → [colección] → Imagen**. Un banner asignado en un bloque tiene prioridad sobre esa imagen. Esta alternativa permite configurar tantas colecciones como necesites sin añadir bloques.

## Formato y comportamiento

- Escritorio: recomendado **2000 × 650 px**.
- Celular: recomendado **750 × 600 px**. Si no hay imagen móvil, se muestra completa la de escritorio.
- Las imágenes mantienen sus proporciones. No se cortan los logos ni los textos.
- Puedes elegir todo el ancho o un ancho contenido, y mostrar u ocultar el nombre bajo la imagen.
- Sin imagen, la sección queda oculta para los visitantes y el encabezado normal conserva el nombre de la colección. En el editor aparece una ayuda de configuración.
- El catálogo general `/collections/all` no muestra el banner de una editorial.

No se han creado banners ni atribuido logos a editoriales: las imágenes y asignaciones se seleccionan desde Shopify.
